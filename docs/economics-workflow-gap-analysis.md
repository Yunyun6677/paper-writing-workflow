# 经济学论文全流程能力评估（2026-09-08）

## 结论

Research OS 已具备较强的“文献真实性—全文获取—Zotero—多引擎实证—LaTeX”底座，但四个 specialist skill 之间缺少论文级总控。v0.7.0 新增 `economics-paper-workflow`，把研究设计审批、可追溯写作、独立审计与投稿复现包纳入统一生命周期。

这不意味着系统已覆盖所有计量方法。当前应区分“全流程组织能力”和“具体估计器证书”：前者已形成，后者仍按测试逐项准入。

## 尚需逐步建设的能力

1. **方法适配器**：现代 DID、IV/弱工具、RD、合成控制/SDID、DML、非线性结果、复杂抽样、空间网络与动态面板；每项都必须通过合成真值、公开复现和适用范围测试。
2. **研究治理**：预分析计划、探索区与确认区分离、多重检验、敏感数据分级、IRB/伦理提示和匿名化检查。
3. **数据工程**：变量字典 schema、样本流图、合并血缘、地理与面板数据适配、受授权云备份。
4. **发表工程**：期刊最新指南抓取、匿名稿/标题页、多版本构建、在线附录、编辑信和逐条审稿回复。
5. **质量评估**：基于已发表复制包的回归测试集、失败案例库、跨模型/跨软件一致性和写作盲审评分。

优先级不是“skill 越多越好”，而是先完成一个可验证的纵向闭环，再逐项扩大方法与期刊覆盖。所有 staged 能力必须在 README 与运行回执中保持未认证状态。

## 安全与新手设计

- 默认私有：`projects/`、原始数据、受限全文、Zotero 状态和凭据不进入 Git。
- 默认暂停：登录、验证码、付费、外部上传、投稿和改变既定识别设计需要人类操作或授权。
- 默认不覆盖：项目初始化器拒绝同名目录；探索结果必须显式晋升。
- 默认可解释：每个阶段给出最小输入、状态、产物、失败原因和下一步。
- 默认可追溯：引用指向全文证据，数字指向模型产物及哈希，写作变化进入 revision log。

## 路线图准则

先进性不以 skill 数量衡量，而以“一个结论能否回到来源、一个模型能否回到设计、一个数字能否回到运行、一次修改能否回到理由”衡量。新增方法必须通过 `method-coverage.md` 的准入测试；新增外部服务必须先完成许可、隐私、凭据和失败回退设计。
