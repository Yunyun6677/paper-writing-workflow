# v0.11.0 Release Notes

发布日期：2026-09-15

v0.11.0 将 Research OS 从可持久化的 Agent Kernel 推进到可执行的受限 Research Agent System：模型只能提交结构化 observation 和 tool request，Runtime 仍是唯一状态迁移者；Tier-1 本地工具、Codex CLI specialist loop、独立 verifier、故障恢复、SQLite 状态后端、科学记忆、least-context packing 和本地隐私追踪均有真实测试回执。

## 发布门

- 10/10 公开论文全文、数据、结果和回执通过 SHA-256 与状态复核。
- 4/10 预声明目标严格匹配作者表格。
- 2/10 在公开数据版本的预声明容差内匹配。
- 2/10 只认证核心系数，不认证缺失的权重或聚类推断。
- 1/10 只认证方法执行路径，不冒充原表复现。
- 1/10 完成但保留设计矩阵秩亏警告。
- 故障注入覆盖模型/工具超时、错误 observation、缺失制品、重复副作用、进程重启、checkpoint 损坏、verifier 拒绝和人工拒绝。

## 重要边界

本版本不是“自动完成科研”的声明。OpenAI Agents SDK 尚未在当前机器完成真实 API 集成测试；LaTeX 编译器仍未发现；OpenAlex、Unpaywall、Zotero 写入和授权浏览器/CNKI 仍按能力矩阵中的具体测试状态理解。十篇基准证明执行、验证、恢复和证据链合同，不证明所有因果识别假设或论文全部结果。

完整数值与来源见 `docs/ten-paper-release-benchmark.md`；机器入口为 `scripts/verify_ten_paper_release_gate.py`。
