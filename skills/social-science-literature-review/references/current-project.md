# Current project: 贸易开放与农村基层政治参与

## Primary question

国际经济与贸易开放如何改变政治组织、地方治理与政治参与，并经由哪些经济和组织机制影响中国农村基层政治参与？村委会选举投票和村民大会参加次数是本文的经验操作化结果，而不是文献综述的起始分类框架。

## Outcome families

- 村委会选举：是否投票、投票率、候选人竞争、选举参与和退出。
- 村民会议/村民代表会议：参加次数、出席概率、发言、议事和公共事务参与。
- 只把政治信任、抗议、党派投票或民族主义作为机制或外部比较，不能直接替代上述基层参与结果。

## Exposure and mechanisms

- 贸易暴露：进口竞争、出口机会、关税下降、贸易冲击、产业和就业暴露。
- 候选机制：收入与就业冲击、人口迁移、机会成本、集体行动、信息与社会网络、地方财政、政府回应、精英俘获、政治效能感。

## Search languages

中文与英文并重。纳入经典文献，不设置机械起始年份；系统检索重点覆盖最近二十年。优先同行评审论文，并纳入高质量工作论文和权威政策报告。

## Method orientation

重点评价准实验与因果识别，同时纳入能够解释中国村民自治制度和参与机制的高质量制度研究。不得把相关性结果改写成因果结论。

## Output

中文文献综述，引用格式为 GB/T 7714。逐篇文献采用结构化全文精读，最终按照理论机制、经验识别与研究争议组织，而非逐篇罗列摘要。

正式综述按以下递进关系展开：

1. 国际经济与贸易对政治组织、政治分化、代表关系、国家与地方治理能力的影响；
2. 农村基层治理中影响选举投票和其他参与行为的制度、资源、信任、网络与组织因素；
3. 贸易开放经就业、迁移、地方财政、政策下沉和组织能力进入农村治理的桥梁；
4. 最后才落到“外贸下乡—农村基层政治参与”的交叉空白和本文研究位置。

创新点组合、评分和新研究方向必须作为独立报告输出，不得改变正式论文文献综述的上述学术逻辑。正式综述可以正常说明研究缺口与本文位置，但不设置“创新点评分”或“创新方案”章节。
