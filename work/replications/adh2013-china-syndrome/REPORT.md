# 《中国冲击》Table 3 复现报告

## 1. 复现对象

- 论文：David H. Autor、David Dorn、Gordon H. Hanson，*The China Syndrome: Local Labor Market Effects of Import Competition in the United States*，American Economic Review 103(6)，2013，2121-2168。
- DOI：<https://doi.org/10.1257/aer.103.6.2121>
- 论文来源：MIT 作者档案。
- 数据与代码来源：David Dorn 作者主页公开的 `Autor-Dorn-Hanson-ChinaSyndrome-FileArchive.zip`。
- 本次范围：数值复现论文 Table 3 的六个 2SLS 规格，而不是宣称整篇论文的所有表图均已复现。

## 2. 论文的识别逻辑

论文研究 1990-2007 年中国进口竞争如何影响美国地方劳动力市场。观察单位是美国通勤区（commuting zone, CZ）与时期的组合。作者将 722 个通勤区在 1990-2000 和 2000-2007 两个时期堆叠，得到 1,444 个观察值；不足十年的后一时期被换算为十年等价变化。

核心解释变量是每名劳动者面对的中国进口暴露变化。该指标用通勤区期初产业就业结构加权行业层面的美国对华进口增长。为缓解美国本地需求冲击带来的内生性，作者使用中国对八个其他高收入经济体的行业出口增长构造工具变量，并使用更早一期的产业就业权重。结果变量是制造业就业占工作年龄人口比重的十年等价变化。

Table 3 使用加权 2SLS：权重为期初通勤区人口占全国人口的份额，所有规格含常数项和 2000-2007 时期虚拟变量，标准误在州层面聚类。六列依次加入期初制造业就业占比、九大 Census division 地区虚拟变量、人口与劳动力特征、职业常规化程度及可离岸性指标。

## 3. 数据与原代码审计

公开包中的 `workfile_china.dta` 包含 722 个通勤区、两个时期和论文主表所需变量。作者的 `czone_analysis_ipw_final.do` 使用相对路径、会创建后删除 `temp.dta`，并依赖 `eststo/esttab` 输出表格。为了保护原始包并避免依赖未声明的扩展命令，本次没有直接执行整份作者 do 文件。

我们生成了一份最小化 Stata 脚本，只读取原始 DTA，运行 Table 3 的六个内置 `ivregress 2sls` 规格，并把结果写入隔离的 `run/stata` 目录。同时用 NumPy/Pandas 独立实现加权 2SLS、州级聚类 sandwich 协方差和加权第一阶段，结果写入 `run/python`。原始压缩包、原始数据、原始代码和作者日志均保持不变。

## 5. 对结果的解释边界

第 2 列估计表明，每名劳动者进口暴露增加 1,000 美元，与制造业就业占工作年龄人口的比重在十年内下降约 0.61 个百分点相对应。论文将该结果解释为工具变量识别出的进口供给冲击效应，但这一解释依赖排除限制、跨国进口工具变量的相关性以及期初产业结构不会通过其他渠道影响结果等假设。数值复现证明代码与数据能够重建表格，不等于重新证明这些识别假设。

## 6. 平台测试结论

本次真实测试证明平台可以完成：公开论文与复现包获取、来源与哈希记录、PDF/README 阅读、原代码静态审查、DTA 读取、根据论文规格生成安全代码、Stata 16 批处理、Python 独立估计以及跨引擎结果核验。

测试也暴露了三个需要继续建设的能力：

1. 下载器需要断点续传、镜像优先级和失败交接；校园网络下 Dropbox/GitHub 出现过连接重置，而作者服务器最终成功。
2. 当前通用请求 schema 尚未正式支持工具变量、分析权重与聚类协方差的组合；本次通过项目专用、已核验的代码实现。
3. 原作者代码安全扫描应产品化，区分只读估计命令、临时文件删除、外部软件包依赖和系统命令，再决定是原样运行还是生成最小复现脚本。
