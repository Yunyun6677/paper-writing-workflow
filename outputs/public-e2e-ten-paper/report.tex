\section{能力与边界}

十篇组合实际覆盖随机实验、现场实验、线性概率模型、HC1、传统与交互 DID、人口加权 TWFE、近票选举与资格阈值 RD、跨国 IV/2SLS、shift-share IV、聚类推断和图表生成。论文 PDF 与原始数据位于 Git 忽略的本地工作区；公开仓库只保存执行器、来源 URL、固定版本、哈希、非原始结果和审计回执。

综合门通过不能代替识别假设审查。只有严格匹配的目标可以称为数值复现；系数级或方法级案例必须连同警告一并呈现。
