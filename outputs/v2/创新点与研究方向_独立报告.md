# 创新点与研究方向：独立报告

> 本报告独立于正式文献综述。它不改变正式综述“国际贸易与政治组织—农村治理决定因素—外贸下乡—交叉空白”的学术结构，也不把尚未完成的数据和识别设计写成论文已经实现的贡献。

## 一、总体判断

七专家委员会从文献地图中的交叉缺口、测量不足和识别边界生成了五个方向，并由方法专家审计可行性、检索专家进行定向反向检索。当前优先级最高的三项是：

1. 构建基层参与阶梯，先回答“实际测到了哪一层参与”；
2. 区分居民资源与组织资源双通道，再回答“为何发生变化”；
3. 分解自贸区政策组件与动态暴露，最后回答“政策包中的什么造成变化”。

前两项属于带严格范围限制的创新候选，第三项属于识别设计扩展。三项都不能宣称“首次”“无人研究”或“方法首创”。

## 三、Top 1：基层参与阶梯

### 1. 最近文献与未解问题

Pang 和 Rozelle 已经区分本人投票、代投和真实投票程序；张同龙、张林秀区分名义、意愿和完整投票；Olken 则显示进入程序、主观合法性和实际项目选择可能分离。反向检索还发现，Luo 等（2011）已经在同一村级研究中同时涉及选举与村民代表会议次数。因此，本方向不能声称首次同时研究投票与会议，其新意必须限定为建立跨渠道、跨结果层级的完整测量结构。

### 2. 建议贡献

将基层政治参与分为：

`资格与可及性 → 实际进入 → 独立表达 → 意见采纳 → 资源配置影响`

工作稿的“是否参加村委会投票”和“村民大会参加次数”主要处在“实际进入”层。后续应增加本人写票、本人投箱、代投、会议实际供给、受邀、发言、议案提出、意见采纳和项目结果，检验开放究竟改变参与成本、组织供给还是实际政治影响。

### 3. 可证伪条件

如果政策只改变自报参与，而不改变可核验的会议供给、本人投票、发言或意见采纳，且差异可由社会赞许偏差或问卷口径解释，则“参与渠道重排”不成立。

### 4. 数据与识别

在现有边界局部设计中预先确定主次结果并调整多重推断；若能获得政策前后重复数据，再使用分期事件研究或局部 DID。没有更细结果时，应把贡献收窄为“两种进入型参与指标在边界处方向不同”。

## 四、Top 2：居民资源—组织资源双通道

### 1. 最近文献与未解问题

开放—农村文献说明出口机会会改变务工、迁移网络和收入；农村治理文献说明国家能力、事实权力、资源来源和组织嵌入会改变自治与公共品。反向检索发现 Ye 等（2026）已经使用省级多期 DID 研究自贸区与地方治理质量。因此，本方向不能声称首次把自贸区同治理能力联系起来，其边界必须收紧为：在村级层面同时识别居民资源与组织资源，并说明二者如何共同塑造基层参与。

### 2. 建议贡献

- 居民侧：就业行业、通勤、迁移日历、全年在场、收入与社会网络；
- 组织侧：村级财政、上级项目、会议召开、干部任务、签批权与事实权力。

尤其可以检验两组机制的交互：迁移者是否在通知、代理投票或会议动员能力更强的村庄中仍能保持参与。

### 3. 可证伪条件

若更直接的居民和组织指标均未在政策边界处变化，或它们同参与结果没有预注册的一致异质性关系，则双通道解释应被否定，主结果只能作为未分解的政策包局部约化效应。

### 4. 数据与识别

空间 RD 可承担主效应，但不能通过把政策后变量加入结果回归来宣布因果中介成立。机制检验至少需要客观供给结果、明确时序、预定异质暴露，理想情况下还需要独立工具、随机干预或重复期资料。

## 五、Top 3：自贸区政策组件与动态暴露

### 1. 最近文献与定位修正

自贸区多期 DID、自贸区空间断点以及开放政策的空间 RD 都已有先例，自贸区与地方治理质量之间的关系也已有研究。因此，该方向不是方法创新，而是把既有识别工具整合并下沉到村级政治参与的设计扩展。

### 2. 建议贡献

编码批准、挂牌、扩围和政策清单，构造三类暴露：

- 市场与贸易暴露：出口、可贸易行业和企业供应链联系；
- 空间与基础设施暴露：交通、园区和公共项目；
- 行政与组织暴露：财政项目、干部任务和监管协同。

在有数据时利用政策批次、边界段和产业结构构造动态及异质处理，避免把“自贸区”名称直接当作单一贸易处理。

### 3. 可证伪条件

如果效应在政策前已经出现，仅由开发区或行政边界重叠驱动，剔除交通节点后消失，或无法将任何组件暴露同结果联系起来，就不能声称识别政策动态或具体组件。

### 4. 数据与识别

优先完成政策时序、边界重叠、预处理连续性、空间排序、溢出和空间相关审计；有重复期数据时可结合分期事件研究，空间断点仍只承担边界附近的局部比较。

## 六、暂不进入 Top 3 的方向

### 迁移条件下的制度可及性

已有迁移—投票研究使这一方向本身不再新颖。真正可推进的是“开放冲击×制度缓冲”：代理投票、组织通知或远程参与安排是否降低迁移者的参与成本。它要求选举日、迁移日历和程序资料。

### 治理能力—自治替代的客观测量

该方向理论价值高，但村级财政、签批权、会议召集和干部安排数据难以标准化，且可得性较低。没有客观组织数据时，只能使用权威认知和公共品作为辅助结果，不宜把该方向置于论文的首要贡献。

## 七、建议的实际推进顺序

1. 先盘点当前调查数据能否区分本人投票、代投、会议供给、出席、发言和采纳；
2. 再寻找村级财政、项目、干部任务及客观权力配置数据；
3. 整理自贸区批准、挂牌、扩围和精确边界，核对开发区与行政边界重叠；
4. 依据可得数据，在 Top 1 与 Top 2 中确定一项核心贡献，把 Top 3 作为识别强化；
5. 在论文中只表述已经被数据和设计实现的贡献，其余保留为后续研究方向。
