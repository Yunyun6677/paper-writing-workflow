# Token经济学与人工智能经济学：第一版交付包

## 先读什么

1. `Token经济学与人工智能经济学_文献综述.md`：正式主题综述。
2. `数字经济学生研究入口.md`：独立选题与设计建议，不能当作已确认原创性结论。
3. `literature-map.svg`：主题、机制与证据边界地图。
4. `verified-bibliography.md`、`evidence-cards/`：书目、已读版本和论证定位。
5. `zotero-audit.json`：文库操作成功与失败记录。

## 必须保留的限制

- 本次为覆盖受限的主题综述，不是穷尽性系统评价。若干重要生成式AI实验、企业创新和推理市场论文仍缺少可用全文。
- 学术论文的工作论文版与期刊版分别记录；正文14%的客服效率数字对应已读2023年NBER版本。
- 原始token数、标价、算力、达标任务成本和经济产出不能混同。
- 上次地图专家遭遇额度限制，整理专家经历403错误。后续从文件接续；不能称此前全部专家已完成，也不能将重复请求视为新的独立证据。
- 研究方向与正式综述分开。未经完整新颖性反向检索的候选保持“潜在方向”标签。
- Zotero是否成功分类与本地是否有全文是两件事；只以审计中的成功条目为准。
